# Windows 11 实机验收

以下是待执行的手动验收，不代表已经通过。建议先用记事本显示 `The gate is locked. Find the silver key.` 进行基线验证，再测试游戏。

- [ ] 解压便携包，在未安装 .NET 的 Windows 11 x64 上直接启动。
- [ ] 缺少英语 OCR 时出现可操作提示；安装系统 OCR 并重启后可识别记事本文字。
- [ ] 填写自己的百度通用文本翻译凭证，框选记事本并翻译为与「门锁着。找到银色钥匙。」意义相近的中文。
- [ ] Ctrl+Alt+R 可以重新框选，Esc / 右键取消后保留旧选区，小于 12×12 像素的选区不会被接受。
- [ ] 在 100%、150%、200% 缩放及带负坐标的第二显示器上，框选范围与实际识别内容一致；按钮、设置和状态栏没有截字。
- [ ] Ctrl+Alt+T 在游戏获得焦点时执行；译文更新时不抢游戏键盘焦点。
- [ ] Ctrl+Alt+P 开启 / 暂停自动识别；文字不变时显示复用译文，关闭窗口后程序与托盘图标均退出。
- [ ] 翻译中暂停自动模式或退出不崩溃；断网、错误密钥、额度不足会显示原因并暂停自动调用。
- [ ] 设置保存后重启，APP ID / 密钥 / 选区保留，但自动模式不自动开启。配置文件内不包含明文密钥。
- [ ] 快捷键被占用时能提示冲突；窗口按钮继续可用。
- [ ] 游戏无边框窗口下可以识别字幕，置顶窗口不挡住所选字幕。独占全屏和受保护画面单独记录兼容性。

发现问题时记录 Windows 版本、显示器缩放、游戏窗口模式和界面错误文字。不要分享密钥、完整配置文件或敏感游戏截图。
